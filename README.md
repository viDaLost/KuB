# КуБ — всё сложится

Интерактивный 3D-тренажёр сборки кубиков 2×2, 3×3, 4×4 и 5×5. Интерфейс на русском языке, адаптирован к телефону, планшету и компьютеру. Работает как статический сайт без сервера, аккаунтов и API-ключей.

## Возможности

- 20 учебных упражнений: 4 для 2×2, 8 для 3×3, по 4 для 4×4 и 5×5.
- Пошаговый показ формул, объяснения, следующий ход, пауза и проверка ручного ввода.
- Свободная сборка: перемешивание, таймер с первого хода, история, отмена и повтор.
- Вращение камеры мышью или пальцем, масштабирование, повороты слоёв смахиванием по наклейкам.
- Все внешние и внутренние слои, широкие повороты, обратные и двойные ходы.
- Решатель 3×3 на основе двухфазного алгоритма cube.js в отдельном Web Worker. Для остальных размеров — проверяемое решение обратной историей. При сбое решателя 3×3 также используется история.
- Развёртка всех граней, буквы на наклейках, настройка скорости, звук, отключение анимации.
- Библиотека формул и локальное сохранение прогресса, рекордов и свободного состояния.
- Шрифты и зависимости включаются в сборку: во время работы сайт не загружает библиотеки с CDN.

Каждый урок — самостоятельный подготовленный случай для изучения конкретного приёма. Переключение урока заново подготавливает кубик. Курс не выдаёт универсальную послойную инструкцию для произвольного перемешивания. В разделах 4×4 и 5×5 показаны основные приёмы редукции; это вводные упражнения, а не полный каталог всех паритетов и случаев.

Рекорд записывается только после перемешивания и самостоятельной сборки без подсказок, отмены или ввода формулы. Прогресс хранится в `localStorage` данного браузера. При очистке данных браузера он удаляется.

## Запуск

Требуется Node.js 24 LTS.

```sh
npm ci
npm run dev
```

Проверка и сборка:

```sh
npm test
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. Относительный `base` позволяет публиковать его по адресу `/KuB/`, на отдельном домене или в другой подпапке.

## GitHub Actions и GitHub Pages

Workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml) автоматически запускается при push в `main`, pull request в `main` и вручную через **Actions → Test, build and deploy → Run workflow**.

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **GitHub Actions**. Это однократная настройка нового репозитория.
3. Запустите workflow вручную либо отправьте commit в `main`.
4. Actions установит зависимости по lock-файлу, проверит механику и решатель, соберёт проект, загрузит артефакт и опубликует сайт.

Ожидаемый адрес после успешной публикации: **https://vidalost.github.io/KuB/**. Точный адрес находится в успешном шаге Deploy и в Settings → Pages. До завершения deployment этот адрес может возвращать 404.

Отдельные секреты и personal access token для workflow не нужны. Используется стандартный `GITHUB_TOKEN` с минимальными правами. Если первая публикация сообщает `Not Found` / `Get Pages site failed`, проверьте, что Source в Settings → Pages установлен в **GitHub Actions**, затем повторите workflow. Проверка pull request выполняет только тесты и сборку, без публикации.

## Управление

| Действие | Управление |
| --- | --- |
| Поворот внешней грани | Кнопки U, D, L, R, F, B или одноимённые латинские клавиши |
| Обратный поворот | Переключатель «Обратно» или Shift + клавиша |
| Половина оборота | Переключатель ×2; запись R2 |
| Внутренний слой | Меню слоёв на 4×4/5×5; запись 2R |
| Два слоя вместе | Меню слоёв на 4×4/5×5; запись Rw |
| Следующий ход урока/решения | Кнопка со стрелкой или Пробел, когда фокус не на кнопке |
| Отмена / повтор | Кнопки или Ctrl/⌘+Z / Ctrl/⌘+Y |
| Осмотр кубика | Режим «Обзор», перетаскивание |
| Ход смахиванием | Режим «Слои», смахивание по наклейке |

Буквы обозначают исходные оси: U — жёлтая, F — зелёная, R — красная, D — белая, L — оранжевая, B — синяя грань в собранном состоянии. Вращение камеры эти оси не меняет. Направление поворота определяется при взгляде на конкретную грань снаружи. Входные алгоритмы используют стандартную латинскую запись; символы `′` и `’` также принимаются как штрих.

## Структура

```text
src/cube.js           Математическая модель N×N без зависимости от 3D
src/view.js           Three.js, анимация, камера и жесты
src/main.js           Режимы, управление, таймер и сохранение
src/lessons.js        Содержимое уроков и объяснения ходов
public/solver.worker.js  Изолированный решатель 3×3
public/vendor/          Оригинальные browser-скрипты cube.js 1.3.2 и лицензия
src/style.css        Адаптивный интерфейс
tests/cube.test.js    Сравнение с cube.js, слои, обратимость и уроки
```

Тесты сверяют соглашения всех внешних ходов с независимой моделью cube.js, проверяют внутренние и широкие повороты всех размеров, сохранность наклеек и деталей, длинные перемешивания, все учебные случаи и реальные решения 3×3, включая повороты средних слоёв.

Используются Three.js (MIT), cube.js (MIT), Manrope (OFL-1.1) и Vite (MIT). Лицензии включены в установленные npm-пакеты; сведения о зависимостях — в lock-файле. Основной рендерер использует WebGL 2, включая Safari на iOS. Если WebGL отключён, автоматически включается CSS 3D-рендерер с той же сценой, камерой и математикой; на больших кубиках он может работать медленнее.
